本次提交会发生什么

  1. 地区集合与额度被归一化为查询身份；地区名称和勾选顺序不参与身份。
  2. 若身份此前已成功，直接返回保存的噪声结果，不再抽样、不再扣费。
  3. 否则在事务内校验剩余预算并扣减整笔费用；失败则不扣费。
  4. 扣减成功后执行拉普拉斯抽样，原始值与展示值分别写入记录。

    保留记录后的地区人数真值

    怎么读误差

    1. 真值是“每人保留一条记录”之后的人数，不是原始记录条数。
    2. 查询返回的 raw 加噪值 = 真值 + 拉普拉斯噪声，尺度 ns = 1/ε。
    3. 约 95% 的拉普拉斯噪声落在 ±3·ns 内；ns=2 时单次误差常有数人。
    4. 展示值 max(0, raw) 在真值较小、ns 较大时更容易被抬到 0 附近。
    5. 每次重放返回同一条保存结果，因此误差不会因刷新而变化。
